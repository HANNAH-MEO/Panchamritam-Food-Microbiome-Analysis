# Panchamritam Food Microbiome Analysis

## Project Overview

This repository contains the microbiome dataset and R scripts used for the analysis of bacterial community composition during the fermentation of Panchamritam, a traditional food preparation.

The study investigates temporal changes in microbial community structure and explores associations between microbial taxa and iron-related parameters.

## Dataset Description

The repository contains the following datasets:

### 1. OTU Table
- File: `OTU_Table.xlsx`
- Contains operational taxonomic unit (OTU) abundance data obtained from 16S rRNA gene sequencing.
- Includes taxonomic annotations of bacterial communities.

### 2. Metadata
- File: `Metadata.xlsx`
- Contains sample-level information, including subject/sample identifiers, fermentation timepoints (0, 6 and 12 hours), environmental parameters and iron measurements.

## R Scripts

The `Scripts` folder contains the R scripts used for data processing, statistical analysis and visualization.

Analyses include:
- Alpha diversity analysis
- Bray–Curtis beta diversity and PCoA
- Differential microbial abundance analysis
- Spearman correlation analysis
- Microbial association analysis

## Software and Packages

Analyses were performed using R. The scripts specify the packages and functions required for analysis.
